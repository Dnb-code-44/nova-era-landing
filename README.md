# Nova Era | Saúde Integrativa - Landing Page

Landing page enxuta e direta para a clínica Nova Era em Bethaville I, Barueri - SP.

## 🎯 Conceito

Inspirada na navegação rápida do dr.consulta, com foco total em facilitar o agendamento via WhatsApp. Ideal para acesso mobile através da bio do Instagram.

## 🎨 Identidade Visual

- **Paleta:** Off-White Areia, Bege Suave, Marrom Carvão e Dourado Fosco
- **Tipografia:** Cormorant Garamond (títulos) e Plus Jakarta Sans (corpo)
- **Estilo:** Clean, sofisticado e sem elementos genéricos de IA

## 🚀 Estrutura

1. **Header Minimalista** - Logo + CTA direto
2. **Hero + Barra Rápida** - 4 atalhos diretos para WhatsApp
3. **O Diferencial** - 4 tópicos objetivos com foto
4. **Localização e Rodapé** - Mapa + informações práticas

## 🛠️ Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- Lucide React (ícones)

## 📦 Instalação

```bash
npm install
```

## 🏃 Executar

```bash
npm run dev
```

## 🔨 Build

```bash
npm run build
```

## 📱 Responsivo

Mobile-first design, totalmente responsivo para todos os tamanhos de tela.
